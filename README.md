### [Autonomous CLI Coding Agent](https://github.com/Ajeenckya5/CLI_AI_Agent)
![Python](https://img.shields.io/badge/-Python-3776AB?style=flat-square&logo=python&logoColor=white)
![LLM](https://img.shields.io/badge/-LLM-8B5CF6?style=flat-square)
![ReAct](https://img.shields.io/badge/-ReAct-0EA5E9?style=flat-square)

![DPO](https://img.shields.io/badge/-DPO-10B981?style=flat-square)

Production-grade coding agent built **from scratch with zero framework dependencies** (no LangChain, AutoGen, or CrewAI). Raw HTTP to LLM API, 11 tools, ReAct planning loop, cross-session memory, JSONL tracing, and an RLAIF scoring loop that collects DPO preference pairs via Grok 4.

| Task completion | **100% (5/5)** |
| Unit tests passing | **14 / 14** |
| Latency vs LangChain equivalent | **7.5× faster** (0.8 ms vs 5.7 ms) |
| Cold-start overhead | **zero** |

### [Self-Improving LLM Agent](https://github.com/Ajeenckya5/Self_Improving_LLM_Agent)
![QLoRA](https://img.shields.io/badge/-QLoRA-7C3AED?style=flat-square)
![LLaMA-3.2](https://img.shields.io/badge/-LLaMA--3.2-EE4C2C?style=flat-square)
![ChromaDB](https://img.shields.io/badge/-ChromaDB-FF6B6B?style=flat-square)
![Knowledge Distillation](https://img.shields.io/badge/-Knowledge_Distillation-10B981?style=flat-square)

Closed-loop self-improvement system: **Grok 4** (teacher) annotates failure traces → **QLoRA fine-tunes LLaMA-3.2-1B** (student) → corrective strategies stored in **ChromaDB** → retrieved on next similar task.

|--------|--------|
| Task completion (Tau Bench / WebArena) | **90% vs 71% baseline** |
| Memory reduction (4-bit NF4 quantization) | **60% reduction** |

### [Multi-User Email RAG](https://github.com/Ajeenckya5/LLM_RAG)
![FastAPI](https://img.shields.io/badge/-FastAPI-009688?style=flat-square&logo=fastapi&logoColor=white)
![pgvector](https://img.shields.io/badge/-pgvector-4169E1?style=flat-square)
![Mistral 7B](https://img.shields.io/badge/-Mistral_7B-FF6B6B?style=flat-square)
![JWT](https://img.shields.io/badge/-JWT_Auth-000000?style=flat-square)
![PostgreSQL](https://img.shields.io/badge/-PostgreSQL-336791?style=flat-square&logo=postgresql&logoColor=white)

Local-first RAG over **10,000+ emails** with **SQL-enforced per-user retrieval isolation** — `WHERE user_id = :uid` runs before cosine ranking so User B cannot surface User A's chunks. E5-small-v2 embeddings · Mistral 7B GGUF via llama-cpp · pgvector cosine search · JWT auth.
